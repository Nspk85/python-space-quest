# Pyodide 0.26.4

These files are the core of [Pyodide](https://pyodide.org) 0.26.4, copied unchanged from the `pyodide` npm package (licensed Apache-2.0). They let the Code Pad run real Python (CPython 3.12) inside the browser, so learners don't need to install an app.

Pyodide project and license: https://github.com/pyodide/pyodide
