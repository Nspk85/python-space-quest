Lesson 1 · About 30 minutes

Your First Spell

Story: Every time the crew does something great, Py-Bot cheers. But writing two cheer lines every time is boring! Let's turn the cheer into a spell that Py-Bot can cast with one word.

The big idea: def makes a function, and name() uses it

def (short for "define") writes a new spell into the book. The indented lines are what the spell does. Writing the spell doesn't do anything yet! To cast it, you call it: write its name with brackets, like cheer().

def cheer():                          ← "here's a new spell called cheer"
····print("🎉 Hip hip hooray!")       ← what the spell does
····print("🚀 Go crew go!")
                                      ← (nothing happens yet!)
cheer()                               ← cast the spell: both lines run

Type it and run it +10 XP

def cheer():
    print("🎉 Hip hip hooray!")
    print("🚀 Go crew go!")

print("Mia fixed the engine!")
cheer()
print("Leo found the map!")
cheer()
Mia fixed the engine!
🎉 Hip hip hooray!
🚀 Go crew go!
Leo found the map!
🎉 Hip hip hooray!
🚀 Go crew go!

Change it! +10 XP

  • Add a third line to the spell, like print("⭐⭐⭐"). Now every cheer has it. You only changed one place!
  • Delete the two cheer() lines and run it. The spell is written, but nobody cast it, so the cheer never appears.
  • Cast it inside a loop: for i in range(3): then an indented cheer().

Spell-writing rules

  • Function names follow the same rules as box labels: small letters, underscores instead of spaces, like draw_rocket.
  • The def line ends with () and a colon :.
  • Write the spell above the place where you cast it. Python reads from the top, so it has to learn the spell first.

Spell Ingredients

Story: Py-Bot wants a welcome spell for new crew members. But each person has a different name! Spells can take ingredients, so the same spell works for everyone.

The big idea: put a box name in the brackets

In def greet(name):, the word name is a box that's filled when you cast the spell. greet("Mia") puts "Mia" in the box, and greet("Leo") puts "Leo" in it. Programmers call these ingredients parameters.

def greet(name):          greet("Mia")
          ▲                      │
          └──── "Mia" goes into ─┘
                the name box

Type it and run it +10 XP

def greet(name):
    print("Welcome aboard,", name, "! 👋")

greet("Mia")
greet("Leo")
greet("Py-Bot")
Welcome aboard, Mia ! 👋
Welcome aboard, Leo ! 👋
Welcome aboard, Py-Bot ! 👋

Change it! Two ingredients +10 XP

Spells can take more than one ingredient. Separate them with commas:

def draw_line(symbol, length):
    print(symbol * length)

draw_line("⭐", 5)
draw_line("~", 20)
draw_line("🍕", 3)
  • Run it, then add your own draw_line(...) with a different symbol.
  • Swap the order: draw_line(5, "⭐"). What happens? (The order of ingredients matters!)
  • Make greet ask for the name: greet(input("Your name? "))

Lesson 3 · About 35 minutes

Spells That Give Back

Story: Py-Bot made a spell that works out space math, but it just prints the answer on the screen. Py-Bot wants to keep the answer in a box to use later. Some spells need to hand something back!

The big idea: return hands an answer back

return sends a value back to the place where the spell was cast, like a vending machine giving you a snack. You can put it in a box, print it, or use it in more math.

print shows something on the screen. return gives something back to your code. They're different!

Type it and run it +10 XP

def double(number):
    return number * 2

answer = double(21)            # the 42 comes back into the box
print(answer)
print(double(5) + double(10))  # 10 + 20
42
30

Change it! +10 XP

  • Make triple(number) that returns the number times 3.
  • Change return number * 2 to print(number * 2) and run it. Now print(answer) shows None, and the last line crashes, because the spell doesn't give anything back any more, so there's nothing to add up!
  • Spells can return text too: def shout(word): then return word.upper() + "!!!". Try print(shout("hello")).

Lesson 4 · About 35 minutes

Spell Library

Story: Py-Bot's spell book is getting full! Now it's time to use spells together, and even cast spells inside other spells. This is how big programs are built: from lots of small, tidy pieces.

The big idea: small spells build big programs

Break a big job into small spells, each with one job and a good name. Then the main part of your program reads almost like a story: show_title(), play_round(), show_score().

Type it and run it +10 XP

import random

def banner(text):
    print("*" * 20)
    print(" ", text)
    print("*" * 20)

def roll_dice():
    return random.randint(1, 6)

def play_round(player):
    roll = roll_dice()              # a spell inside a spell!
    print(player, "rolled a", roll)
    return roll

banner("DICE BATTLE")
mia = play_round("Mia")
leo = play_round("Leo")
if mia > leo:
    banner("Mia wins! 🏆")
elif leo > mia:
    banner("Leo wins! 🏆")
else:
    banner("It's a tie! 🤝")

  DICE BATTLE
********************
Mia rolled a 5
Leo rolled a 2
********************
  Mia wins! 🏆
********************

The dice are random, so your numbers will be different. Run it a few times!

For grown-ups and group leaders

Leader's guide and answer key: World 5

Functions are a big step: they're about organizing code, not just running it. The two big ideas to keep coming back to are "writing a spell isn't casting it" and "print shows, return gives back".

Common confusions, and what to say
  • "I wrote the function but nothing happened!" Say: "You wrote the recipe, but you haven't cooked it. How do you cast it?"
  • print vs return: a vending machine returns a snack into your hand; a TV screen prints a picture you can't hold. Ask: "Do you need to keep the answer?"
  • Parameters: act it out with the Box Swap cups from World 2. Calling greet("Mia") drops "Mia" into the name cup.
  • Double indentation: a loop inside a function needs 8 spaces. The Code Pad's auto-indent helps.

import random

def banner(text):
    print("*" * 20)
    print(" ", text)
    print("*" * 20)

def ask_question():
    a = random.randint(1, 10)
    b = random.randint(1, 10)
    print("What is", a, "+", b, "?")
    answer = int(input("Answer: "))
    if answer == a + b:
        print("Correct! ✅")
        return 1
    else:
        print("Oops, it's", a + b)
        return 0

score = 0
for i in range(5):
    score = score + ask_question()
banner("Score: " + str(score) + " out of 5")

str() turns a number into text so it can be glued onto other text with +. It's fine for learners to print the score on a separate line instead.

# Wizard's Spell Book by Mia and Leo
import random

def show_menu():
    print("=== WIZARD'S SPELL BOOK ===")
    print("1. Draw a rocket")
    print("2. Roll a dice")
    print("3. Times table")
    print("4. Quit")

def draw_rocket():
    print("   ^")
    print("  |o|")
    print(" <|_|>")
    print("  ***")

def roll_dice(sides):
    return random.randint(1, sides)

def times_table(number):
    for n in range(1, 11):
        print(n, "x", number, "=", n * number)

choice = ""
while choice != "4":
    show_menu()
    choice = input("Pick a spell: ")
    if choice == "1":
        draw_rocket()
    elif choice == "2":
        print("🎲 You rolled a", roll_dice(6))
    elif choice == "3":
        number = int(input("Which times table? "))
        times_table(number)
    elif choice == "4":
        print("The spell book closes. Goodbye! 📕")
    else:
        print("That's not a spell! Try 1, 2, 3 or 4.")
