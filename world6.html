Lesson 1 · About 30 minutes

Packing the Chest

Story: Py-Bot wants to keep the whole crew's names together, in order. Time to pack the first treasure chest!

The big idea: a list holds many things in order

A list goes inside square brackets [ ], with commas between the items. Each item has a position number called an index, and the first one is number 0, just like range() in World 4!

crew = [ "Mia" , "Leo" , "Zoe" ]
index:     0       1       2

crew[0] → "Mia"      crew[2] → "Zoe"      len(crew) → 3

Type it and run it +10 XP

crew = ["Mia", "Leo", "Zoe"]
print(crew)              # the whole chest
print(crew[0])           # the first item (index 0)
print(crew[2])           # the third item (index 2)
print(len(crew))         # how many items?

No phone needed · 10 minutes

Game: Treasure Train

Line up some cups (or chairs) in a row and stick a number on each, starting from 0. That's your list! Put a "treasure" (a paper slip with a word) in each cup.

  • "print(chest[2])!" Someone runs to cup 2 and reads out the treasure.
  • "chest.append("crown")!" Add a new cup to the end of the train with "crown" inside.
  • "chest.remove("coin")!" Take the cup with "coin" out, and everyone after it shuffles along. Their numbers change!
  • "len(chest)?" Everyone counts the cups out loud.
  • Tricky one: "print(chest[10])!" If there's no cup 10, everyone shouts "IndexError!"

What you're learning: lists keep things in order, positions start at 0, and adding or removing changes the positions.

Add and Remove

Story: The crew is exploring the asteroid with a backpack. They find things to pick up, and sometimes they use things up. The backpack list needs to change as they go!

The big idea: lists can grow and shrink

  • backpack.append("snack") adds "snack" to the end.
  • backpack.remove("map") takes "map" out.
  • "torch" in backpack asks: is "torch" in the list? It gives True or False, so it's perfect for if.

Type it and run it +10 XP

backpack = ["map", "torch"]
print("Packed:", backpack)
backpack.append("snack")        # found a snack!
backpack.append("gold coin")    # found treasure!
backpack.remove("map")          # the map blew away
print("Now:", backpack)
if "torch" in backpack:
    print("🔦 We can explore the dark cave!")
Packed: ['map', 'torch']
Now: ['torch', 'snack', 'gold coin']
🔦 We can explore the dark cave!

Lesson 3 · About 35 minutes

Loop the Loot

Story: The treasure chest is full! Py-Bot wants to look at every single treasure, one by one: count it, show it, add up its value. A loop and a list are the perfect team.

The big idea: for item in list:

Instead of range(), you can loop straight over a list. Each lap, the loop box holds the next item. The loop runs once for every item, no matter how long the list is!

Type it and run it +10 XP

planets = ["Mercury", "Venus", "Earth", "Mars"]
for planet in planets:
    print("🪐 Hello,", planet, "!")
print("That's", len(planets), "planets!")
🪐 Hello, Mercury !
🪐 Hello, Venus !
🪐 Hello, Earth !
🪐 Hello, Mars !
That's 4 planets!

Change it! Adding up +10 XP

Lists can hold numbers too. Use a total box (World 4) to add them all up:

coins = [5, 10, 3, 20]
total = 0
for coin in coins:
    total = total + coin
print("Treasure total:", total)
print("Biggest coin:", max(coins))
  • Run it, then add more coins to the list. The loop handles them all automatically.
  • Try min(coins) and sum(coins). Python has shortcuts!
  • Add the last 4 planets to the planet list (Jupiter, Saturn, Uranus, Neptune) and rerun it.

Lucky Dip

Story: The pirates left a lucky dip machine: reach in, and you get a random prize! With lists and random, Py-Bot can make jokes, fortunes, team pickers and quiz games.

The big idea: random.choice(list) picks a random item

In World 3, random.randint picked a random number. random.choice picks a random item from a list, like pulling a name out of a hat.

Type it and run it +10 XP

import random
prizes = ["🍪 space cookie", "🧸 alien teddy", "💎 moon gem", "🧦 smelly sock"]
prize = random.choice(prizes)
print("You reach into the lucky dip...")
print("You got:", prize)
if prize == "🧦 smelly sock":
    print("Ewww! Try again!")
You reach into the lucky dip...
You got: 💎 moon gem

Run it a few times. It's random, so you'll get different prizes!

For grown-ups and group leaders

Leader's guide and answer key: World 6

Lists bring together almost everything so far: loops, ifs, functions and random. The biggest stumbling block is counting from 0. The Treasure Train game is worth playing more than once.

Common confusions, and what to say
  • Index 0: "The index is how many steps from the start. The first item is 0 steps away."
  • IndexError: "3 items means indexes 0, 1, 2. There's no cup 3!"
  • for item in list vs for i in range: use the first when you just need each item, and the second when you need the position too (like matching two lists).
  • Resetting totals: if a total is wrong, check where total = 0 is. It belongs before the loop.
  • Methods: .append() and .remove() are spells that belong to the list, so they go after a dot.

# Mission Packing List by Mia and Leo
import random

def show_list(items):
    if len(items) == 0:
        print("Nothing packed yet!")
    number = 1
    for item in items:
        print(str(number) + ".", item)
        number = number + 1

items = []
wishes = ["Good luck, crew! 🌟", "Fly safe! 🚀", "See you on Mars! 🪐"]
print("🚀 MISSION PACKING LIST (max 5 items)")
choice = ""
while choice != "launch":
    choice = input("add, remove, show or launch? ").lower()
    if choice == "add":
        item = input("What do you want to pack? ")
        if len(items) >= 5:
            print("❌ The rocket is full!")
        elif item in items:
            print("You already packed that!")
        else:
            items.append(item)
            print("✅ Packed", item, "(" + str(len(items)) + "/5)")
    elif choice == "remove":
        item = input("What do you want to unpack? ")
        if item in items:
            items.remove(item)
            print("Removed", item)
        else:
            print("That isn't packed!")
    elif choice == "show":
        show_list(items)
    elif choice != "launch":
        print("Please type add, remove, show or launch.")
print("Final list:", len(items), "item(s).", random.choice(wishes))
show_list(items)
