Lesson 1 · About 30 minutes

Memory Boxes

Story: Every time Py-Bot wants to say your name, you have to type it again. That's a lot of typing for tired thumbs! Let's give Py-Bot a box where it can keep your name.

The big idea: a variable is a box with a label

A variable is like a box with a name tag on it. You put something inside, and later you can ask Py-Bot "what's in the box called name?"

The = sign in Python doesn't mean "equals" like in math. It means "put this into the box".

name  =  "Mia"
 │    │    └─ what goes inside the box
 │    └─ means "put it in"
 └─ the label on the box
name"Mia"
planet"Mars"

Type it and run it +10 XP

name = "Mia"                     # put "Mia" in a box called name
planet = "Mars"                  # another box
print(name)                      # look inside the box
print("Hello,", name)            # a comma joins things with a space
print(name, "is flying to", planet)
Mia
Hello, Mia
Mia is flying to Mars

See how print(name) shows Mia, not the word "name"? No quotes means "look inside the box".

Change it! +10 XP

  • Change "Mia" to your own name, and run again. You only changed one line, but every sentence changed. That's the magic of boxes!
  • Try print("name") with quotes. It shows the word name, because quotes mean "say these exact letters".
  • Try print(Name) with a capital N. You'll get a NameError, because box labels must be spelled exactly the same every time.

Rules for box labels

  • No spaces. Use an underscore instead: ship_name, not ship name.
  • Don't start with a number. player1 is fine, but 1player is not.
  • Use small letters and spell it the same way every time. Score and score are two different boxes!
  • Pick names that make sense, like fuel or pet, so you remember what's inside.

No phone needed · 10 minutes

Game: Box Swap

You need 3 cups or envelopes, some paper slips and a pen. Write a label on each cup: score, fuel, pet.

  1. The leader reads out commands one at a time, like score = 5. A player writes 5 on a slip and puts it in the score cup.
  2. Next command: score = score + 2. The player takes out the slip, works out 5 + 2, throws the old slip away, and puts a new slip saying 7 in the cup.
  3. Mix in others: pet = "cat", fuel = 100, fuel = fuel - 40, pet = "dragon".
  4. At the end, the leader asks: "print(fuel)! What's inside?" Everyone checks the cup.

What you're learning: a box holds only one thing at a time. When you put something new in, the old thing is gone.

Lesson 2 · About 30 minutes

Fuel Tank

Story: The rocket uses fuel as it flies from planet to planet. If the tank gets empty, we'll be stuck in space! Py-Bot needs to keep track of the fuel as it goes up and down.

The big idea: you can change what's in a box

Boxes can hold numbers, and you can swap in a new number any time. The new thing replaces the old thing.

fuel = fuel - 30 looks strange, but Python reads it in this order: first look in the fuel box, then take away 30, then put the answer back into the fuel box.

fuel  =  fuel - 30
  ▲        └───┬───┘
  │            └─ 1. work this out first: 100 - 30 = 70
  └─ 2. then put 70 in the box (the 100 is gone)

Type it and run it +10 XP

fuel = 100                # start with a full tank
print("Fuel:", fuel)
fuel = fuel - 30          # fly to the Moon
print("Fuel:", fuel)
fuel = fuel - 50          # fly to Mars
print("Fuel:", fuel)
Fuel: 100
Fuel: 70
Fuel: 20
fuel at start100
after the Moon70
after Mars20

Change it! +10 XP

  • Add a fuel station stop: fuel = fuel + 60, then print the fuel again.
  • Start with a bigger tank: change the first line to fuel = 200. Every answer changes!
  • Make a game score: start with score = 0, then add score = score + 10 three times and print it.

Lesson 3 · About 30 minutes

Py-Bot Asks Questions

Story: New astronauts are joining the ship! Py-Bot wants to chat with each one, but so far, it only says what you typed in the code. Now Py-Bot will learn to ask and listen.

The big idea: input() is Py-Bot's ears

input("question") shows a question, waits for someone to type an answer, and gives back what they typed. Put the answer in a box so Py-Bot can remember it:

name = input("What is your name? ")
 │       │      └─ the question Py-Bot asks
 │       └─ wait for an answer
 └─ the box where the answer goes

Tip: put a space before the last quote ("name? ") so the answer doesn't squish against the question.

Type it and run it +10 XP

name = input("What is your name? ")    # ask, then keep the answer
print("Welcome aboard,", name)
planet = input("Favorite planet? ")
print(name, "loves", planet)
What is your name? Mia
Welcome aboard, Mia
Favorite planet? Saturn
Mia loves Saturn

Change it! +10 XP

  • Run it again and give different answers. Same code, different result! Let a friend try it too.
  • Remove the space before the last quote in a question. What looks different?
  • Add a third question, like food = input("Favorite space snack? "), and print the answer.

Lesson 4 · About 35 minutes

Number Answers

Story: Py-Bot asked an astronaut how old they are, then tried to work out how old they'll be in 5 years… and CRASHED! Sparks everywhere! Let's find out why.

The big idea: input() always gives back text

Even if you type 10, input() gives back the text "10", like a word written on paper. You can't do math with words! To turn the text into a real number, wrap it in int(). "int" is short for integer, which means a whole number.

First, see the crash

age = input("How old are you? ")
print(age + 5)
How old are you? 10
TypeError: can only concatenate str (not "int") to str

Translation: "You asked me to add text and a number together. I don't know how!" (str means text and int means number.)

Type it and run it: the fix +10 XP

age = int(input("How old are you? "))    # turn the answer into a number
print("In 5 years you will be", age + 5)
print("You have been alive about", age * 365, "days!")
How old are you? 10
In 5 years you will be 15
You have been alive about 3650 days!
int( input("How old are you? ") )
│    └──────────┬─────────────┘ │
│               └─ 1. ask the question, get text "10"
└─ 2. turn the text into the number 10
   Count the brackets: 2 open, so 2 close at the end!

Change it! +10 XP

  • Run it and type a word like ten instead of a number. You'll get a ValueError, because int() only understands digits.
  • Add a line that works out your age in months: age * 12.
  • Fun fact: you can add text to text! Try print("Star" + "ship"). It glues them together: Starship.

Error message decoder: World 2

Read the last line of the red error first, and check which line number it points to. The World 1 errors can still happen too. See the World 1 decoder.

The error says…What it meansHow to fix it
NameError: name 'Ship_name' is not definedPython can't find a box with that label. It's often a capital letter or a spelling difference.Spell the label exactly the same as where you made the box.
NameError for a box you did makeYou used the box before the line that makes it.Move the line that fills the box higher up.
SyntaxError: invalid syntax on a line like ship name = ...Box labels can't have spaces.Use an underscore: ship_name

For grown-ups and group leaders

Leader's guide and answer key: World 2

Run sessions the same way as World 1 (warm-up, story, type and change, challenges, bug hunt, pair activity, quiz, show-and-tell). World 2 is a bigger step: variables are one of the most important ideas in all of coding, so it's fine to spend extra sessions here.

Common confusions, and what to say
  • "Why does fuel = fuel - 30 make sense? It's not true!" Say: "In Python, = isn't 'equals'. It means 'put into'. Read the right side first, then put the answer in the box."
  • Quotes or no quotes? Quotes mean "these exact letters". No quotes means "look in the box" (or "it's a number").
  • Box tracing: when a learner is stuck, draw the boxes on paper together and update them line by line. This is the single most helpful thing you can do in this World.
  • The int(input()) brackets are tricky to type on a phone. Encourage counting brackets out loud.
Helping questions for this World
  • "What's inside the box right now? How do you know?"
  • "Is that a word or a number? What do the quotes say?"
  • "Is the label spelled exactly the same in both places?"
  • "Which line runs first? Has the box been filled yet?"
