New skill for this World

Spaces at the start of a line

From now on, some lines of code start with 4 spaces. This is called indenting, and Python uses it to know which lines belong together. It's like the steps under a heading in a recipe.

  • The Code Pad helps you: when you press Enter after a line ending in :, it adds the 4 spaces for you.
  • To add 4 spaces yourself, tap the Tab key in the symbol row.
  • To stop indenting, delete the spaces at the start of the new line.

In the examples, the dots ···· in the diagrams show where the 4 spaces go. Don't type dots, just spaces!

Lesson 1 · About 30 minutes

True or False?

Story: Before Py-Bot can make choices, it needs to learn to ask yes-or-no questions. "Is the fuel more than 50?" "Is the password correct?" In Python, the answer is always True or False.

The big idea: comparisons give True or False

A comparison is a question that Python answers with True (yes) or False (no).

SymbolQuestion it asksExample → answer
>Is it bigger than?10 > 3 → True
<Is it smaller than?10 < 3 → False
==Is it the same as?5 == 5 → True
!=Is it different from?5 != 5 → False
>=Bigger than, or the same?7 >= 7 → True
<=Smaller than, or the same?8 <= 7 → False

Remember: one = means "put into the box" (World 2). Two == means "are these the same?" Think of it as asking twice!

Type it and run it +10 XP

fuel = 30
print(fuel > 50)          # is 30 bigger than 50?
print(fuel < 50)          # is 30 smaller than 50?
print(fuel == 30)         # is it exactly 30?
print("Mars" == "mars")   # capital letters matter!

  • "if you are wearing blue: jump!"
  • "if your age > 9: touch your nose! else: touch your ears!"

Lesson 2 · About 30 minutes

If Py-Bot…

Story: The fuel warning light is broken! Py-Bot needs to check the fuel and warn the crew, but only when the fuel is low. When the tank is full, it should stay quiet.

The big idea: if runs code only when something is True

An if line asks a True-or-False question and ends with a colon :. The indented lines underneath only run if the answer is True. If it's False, Python skips them.

if fuel < 20:                     ← the question, then a colon
····print("Warning! Low fuel!")   ← runs ONLY if True
····print("Going to refuel.")     ← this too (same indent)
print("Have a nice flight!")       ← no indent: ALWAYS runs

Type it and run it +10 XP

Run it twice: once typing 10 and once typing 80.

fuel = int(input("How much fuel? "))
if fuel < 20:
    print("Warning! Fuel is low! ⛽")
    print("Flying to the fuel station.")
print("Have a nice flight!")

Lesson 3 · About 35 minutes

Left or Right?

Story: The ship lands on a strange planet with two paths. Py-Bot asks which way to go, and something different happens on each path. This is how choose-your-own-adventure games work!

The big idea: else and elif

  • if: "If this is True, do this."
  • elif (short for "else if"): "Otherwise, if this is True, do this instead." You can have as many as you like.
  • else: "If none of those were True, do this." It has no question, just a colon.

Python checks them in order from the top, and only one path runs: the first one that's True.

          ┌─ "left"?  ──yes──▶ 👽 friendly alien
answer ───┤
          ├─ "right"? ──yes──▶ 💦 space puddle
          │
          └─ anything else ──▶ 🤖 "I don't know that way"

Type it and run it +10 XP

Run it 3 times: type left, then right, then something silly like banana.

answer = input("Which way? left or right? ")
if answer == "left":
    print("You meet a friendly alien! 👽")
elif answer == "right":
    print("You fall into a space puddle! 💦")
else:
    print("Py-Bot doesn't know that way. 🤖")
print("The adventure continues...")
Which way? left or right? left
You meet a friendly alien! 👽
The adventure continues...

Change it! +10 XP

  • Type Left with a capital L. Which path runs? Why?
  • Add a third path: elif answer == "up": with your own surprise.
  • Magic trick: add .lower() after input(...) like this: answer = input("Which way? ").lower(). Now LEFT and Left work too, because .lower() turns the answer into small letters.

For grown-ups and group leaders

Leader's guide and answer key: World 3

Run sessions the same way as before. World 3 introduces indentation, which is the most common source of bugs for beginners. Expect lots of IndentationErrors at first, and celebrate them as clues!

Common confusions, and what to say
  • = vs ==: "One equals puts something in a box. Two equals asks a question."
  • Indentation: "The spaces show which lines belong to the if, like items under a heading in a list."
  • Text vs numbers: if a number comparison never works, check for a missing int().
  • elif order: act out the bug hunt in Lesson 3 like the If-Machine game. Only the first True path wins.
  • Capitals: "Left" and "left" are different. .lower() is a handy fix.
Helping questions for this World
  • "Is that question True or False right now? How do you know?"
  • "Which lines belong to the if? How can you tell?"
  • "Can you add a print to see what's in the box before the if?"
  • "Which path did you expect? Which one ran?"
